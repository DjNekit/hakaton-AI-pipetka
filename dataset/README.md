# Данные для проверки

- `real/` — паспорта колористических решений (114-ПП) и их ручная разметка;
- `signs/` — официальные образцы дизайн-проектов размещения вывесок Москомархитектуры (902-ПП, mos.ru):
  `DP_TC_OBRAZEC_2021.pdf` (торговый центр), `Dizain-proektOS.pdf` (отдельно стоящая конструкция),
  `Dizain-proektAHK.pdf` (изменение АХК). Это пустые шаблоны, поэтому разметка — незаполненные поля.

В `real/` — реальные паспорта (PDF) и их ручная разметка `*.expected.json`. PDF в git не попадают (`.gitignore`).
Папка `dataset` смонтирована в контейнер backend: положенный сюда паспорт сразу появляется в интерфейсе
(если рядом есть разметка) и участвует в оценке качества.

Сейчас здесь опубликованный паспорт № 19/04406 (Москомархитектура, 2019; скан с OCR-слоем,
[источник](https://moskvakadastr.ru/docs/2022/10/pasport-koloristicheskogo-resheniya.pdf)).
Ручная разметка: 1 ошибка GRF-01, 1 предупреждение DRW-02 и эталонные коды таблицы отделки.
Регрессионные тесты — `backend/tests/test_real.py`, `backend/tests/test_llm.py`.

```bash
docker compose exec backend python -m colorpass eval                                       # все размеченные паспорта
docker compose exec backend python -m colorpass check ../dataset/real/<файл>.pdf --no-llm   # один файл, отчёт в runs/
```

## Сравнения фото: `*.photos.json`

Ручная разметка «фото ↔ развёртка» для `python -m colorpass eval-photos`: для каждого случая — развёртка (`facade`,
id области вида `p12-b1`), фото (`photo` — фото из паспорта), `quad_page` — 4 угла фасада на фото в пикселях листа при
рендере 150 dpi (ЛВ, ПВ, ПН, ЛН), `rect` — видимая часть развёртки в долях, `expected` — `match` / `mismatch`.

## Формат `*.expected.json`

```json
{
  "sample": "moskvakadastr_pasport_19-04406",
  "file": "moskvakadastr_pasport_19-04406.pdf",
  "clean": false,
  "defects": [
    {"rule": "GRF-01", "page_hint": "IV. Фасады объекта", "detail": "В штампе не указан автор проекта"},
    {"rule": "DRW-02", "severity": "warning", "page_hint": "IV. Фасады объекта", "detail": "..."},
    {"rule": "TAB-05", "element": "2.7", "rule_any": ["TAB-05", "TAB-04"], "detail": "..."}
  ],
  "expected_codes": {"Стены / кирпич неокрашенный": ["NCS S 1030-Y30R", "RAL 1002"]},
  "reference_conclusion": "Заключение по паспорту ..."
}
```

`element` (номер позиции таблицы) и `page_hint` (название листа) сужают сопоставление; `rule_any` — допустимые
альтернативные правила; `clean: true` — паспорт без ошибок, должен получить вердикт «соответствует».

## Источники

- ПП Москвы от 28.03.2012 № 114-ПП (ред. от 03.04.2025), mos.ru — требования к составу проекта и паспорта.
- Паспорт колористического решения № 19/04406 (Москомархитектура, 2019), опубликован на moskvakadastr.ru.
- Справочник RAL Classic (`backend/colorpass/data/ral_classic.csv`) — HEX-приближения по таблице w3schools «Colors RAL».
  Это экранные приближения, а не колориметрические эталоны RAL; для промышленного использования заменить на лицензированные данные.
